## FAQ

### What is XCutors?

XCutors is a curated package containing several popular Windows-based executors and a universal loader, designed to provide a unified interface for running Lua scripts within Roblox games.

### Is XCutors safe to use?

The XCutors package itself is scanned and does not contain tool. However, you are responsible for the scripts you choose to execute and should only use scripts from trusted sources.

### Which Roblox executor is included?

The current collection bundles Volt, Synapse Z, Potassium, and Wave. The universal xcutorsLoader allows easy switching between them.

### Do I need to install each executor separately?

No. The XCutors installer or portable package includes all listed executors and the loader, so you can manage them from one place after a single setup.

### How do I update the executors?

XCutors includes an update manager. It will automatically check for updates for each bundled executor, or you can manually check via the Settings menu.

### What scripts can I run?

You can run any Lua script compatible with the respective executor's API. This includes UI libraries, game automation, and customization scripts. Always respect game rules.

### Does it work on macOS or Linux?

No. XCutors and the bundled executors are designed specifically for the Windows operating system due to their runtime dependencies.
